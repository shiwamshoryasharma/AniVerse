# Android tablet edition

2026-11-03 implementation: Android 0.1.0, separate from Windows 2.2.1. Inspect Git tags/releases for publication status; do not infer a published asset solely from this note. Read [operation/build/security limits](../../docs/ANDROID.md).

## Architecture

- Kotlin host (`android/app/src/main/java/app/aniverse/tablet/`) and shared React design. Tablet boot is `frontend/src/android/main.tsx` -> native bootstrap -> dynamic app import, so shared platform detection sees Android. `scripts/build-android.mjs` emits packaged UI plus shared DOM script/focus CSS; no Electron or upscaler runtime enters APK.
- `app/core/db/contracts.ts` separates metadata/settings interfaces from Node SQLite. Keep the Windows Store compatible. `frontend/src/pages/History.tsx` and `styles/history.css` provide common Grid/List history with exact source/episode resume, search/date groups/progress and confirmed clearing.
- minSdk35/Android15, compile37, target35; landscape and smallestWidth>=600dp. Primary Galaxy Tab S10+, compatible other tablets allowed. Native UI feature gates require origin-restricted messages and WebView multi-profile support. No physical Samsung was tested.
- `MainActivity`: appassets-only WebViewAssetLoader and main-frame native-message listener; method/input/pending limits, separate API/general workers. `NativeRequests`: exact official API destinations, no redirects, native-only bearer injection. `NativeAccounts`: verified identity, Keystore AES-GCM and no bearer read API. Normal debug uses official APIs; only explicit android:fixture / -PaniverseFixture=true uses a separate .fixture app ID and local API fixture. Native account entry is disabled in fixture mode. Metadata-mode migration discards only metadata cache, preserving user state.
- `SourceActivity`: original website WebView, source-ID profile, no bridge/device/file grants; separate disposable private UUID profile, TLS rejection, native navigation toolbar and per-source30-day/versioned structural learning. Shared DOM code executes in the page world, not Electron's isolated world. Profile cleanup is attempted at close/startup, not proof of RAM-only sessions.
- `TabletLibrary`/bridge: local schema/snapshots/history/progress/favourites/lists/privacy; corrupt/newer versioned library is retained and rejected, not silently erased. Official provider manual sync uses native auth flags. Pending private edits are skipped while private; records already external are not erased.
- `OfflineStore` copies/validates video and UTF-8 subtitles under app-private UUID paths. SRT is normalized to WebVTT to avoid the observed Media3 SRT in-progress cue/seek failure. Subtitle replacement stages a new private file and switches the DB pointer only after validation/cancellation checks; original input is untouched.
- `ImportOperation`/`ImportJobs`: two process-wide provider-only workers, no queue; native inactivity/absolute deadline, cancellation-aware query/open, polled nonblocking descriptors respecting asset offset/length, exactly-once terminal callbacks, guarded short publication. A provider that ignores metadata/open cancellation can occupy only those two import workers until restart; ordinary controls remain independent.
- `DownloadService`/`TransferChecks`: sequential foreground direct-file queue, guarded redirects/TLS, range+If-Range/validator metadata, disk/byte limits, persisted pause/restart/retry/cancel. State predicates reject stale worker updates. `complete` validates media outside the store lock and atomically publishes row/state/files. No arbitrary source-cookie forwarding, streaming playlist extraction or DRM bypass.
- `OfflinePlayerActivity`: native Media3, local files/captions, resume, +/-10s double tap, brightness/volume swipes, touch lock/PiP. No desktop4K enhancement. Source-backed DUB/SUB catalogue, desktop Workspace/casting/Drive are outside0.1.

## Build and test

`npm run android:debug` / `android:release` regenerate UI before Gradle; `scripts/android.mjs` sets Gradle/user/project/temp caches under `test/cache/android-0.1.0`. Direct Android Studio Gradle builds alone consume existing dist assets. Root package versions Windows separately; Android Gradle versionName/versionCode control APK. Signing config/key are ignored and ACL-restricted; retain existing Android key for updates, never print secrets or publish debug APK.

Native tests/config/provider live under `test/android` via Gradle Kotlin source-set directories. Do not use java sourceDirs for Kotlin under AGP9: it produced misleading NO-SOURCE runs. Native JVM counts must be confirmed from actual XML. Emulator fixture media is generated under test/cache and never bundled in release.

User-facing AVD AniVerse_Tablet_API35, serial emulator-5580, app.debug separate from app.aniverse.tablet; preserve its user-entered source data. Isolated validation uses AniVerse_Validation_API35/emulator-5584. A separate emulator-5582/API34 was used only for actual INSTALL_FAILED_OLDER_SDK rejection and stopped. Never use a physical tablet or unscoped adb/connected tests. ADB/network fixture helpers are under test/e2e; all host testing data stays in root test/.

Initial host qemu headless crashes0xc0000005 were preserved; a later crash also occurred with HardwareDecoder disabled. Auto and software selected the same llvmpipe/SwiftShader stack. Actual host NVIDIA RTX5090 OpenGL renderer with emulator Vulkan/HardwareDecoder disabled subsequently completed source/native-video checks; software and swangle attempts remain failed evidence.
