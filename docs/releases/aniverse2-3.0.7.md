# AniVerse2 3.0.7 for Windows x64

- Adds Dock and Atlas, bringing the layout picker to five options, and expands the dark theme collection.
- Adds ten colour swatches, custom colours, and individual controls for the header, navigation, sidebar, pages, cards, buttons, icons, and floating menus.
- Restyles the title preview and header search. The search field suggests unwatched anime based on recent watch history and genres. Typed results still include watched titles and label completed series.
- Reuses verified source layouts and recent SUB/DUB observations in Rust, with a fresh lookup when a saved pattern stops fitting.
- Adds a filterable session report under **Settings → Privacy & blocking**.
- Adds an AniVerse2-branded Windows setup with a skippable MP4 intro for manual installs.
- Enables AniList and MyAnimeList sign-in using the existing AniVerse client configuration. Restores MyAnimeList token refresh for migrated profiles and reports sync errors per provider.

Existing AniVerse2 installs can update from **Settings → About → Updates**.
