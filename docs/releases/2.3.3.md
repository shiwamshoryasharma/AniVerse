# AniVerse 2.3.3 for Windows x64

- **More supported HLS downloads.** Save complete clear on-demand videos whose manifest-listed TS or fragmented MP4 segments use names such as `.png` or `.webp`, or image MIME types. Actual media bytes are checked; unrelated images and HTML responses are rejected.
- **The playing rendition and audio.** Playlist membership and the visible video's duration help select the playing quality rather than a recent unrelated request. Separate audio renditions are combined with the video while copying the media tracks.
- **Selectable MP4 subtitles.** Accessible WebVTT from the current subtitle track, or a declared default when available, is saved as a `mov_text` subtitle track. Timestamp mappings and segment boundaries are normalized against the media clock. Valid empty caption tracks are omitted.
- **Bounded, private transfers.** Playback references retain required parameters only in memory. Downloads use anonymous public HTTPS requests with checked network destinations. Changing the playing scope cancels the owned transfer; existing destination files are preserved and temporary data is cleaned up.

This download flow supports clear, complete on-demand HLS. Encrypted/DRM-protected streams, live playlists, byte ranges and discontinuities are not supported. Some players do not expose the necessary public references or accessible WebVTT tracks, so this release does not guarantee downloads from every source.

Install with **Settings → About → Check for updates**. This release uses the existing AniVerse Electron profile and signed updater.
