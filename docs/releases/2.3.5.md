# AniVerse 2.3.5 for Windows x64

- Save the same playing video after leaving Save As open while audio playlists and captions update. The download keeps the selected media snapshot; real playback/document/episode changes still revoke it.
- Name Watch downloads with the selected series, season and episode, for example `Series Name - S02E07.mp4`. Explicit season markers in the title/aliases are used; otherwise the suggestion starts at season 1 and remains editable in Save As. Unicode is retained and Windows filename characters are sanitized.
- Retain clear complete VOD HLS video, separate audio and accessible WebVTT subtitle support, no-overwrite behavior, bounded transfer and cancellation cleanup.

Protected/DRM streams and unsupported playlist features remain unsupported. Source availability and format support depend on the selected player.
