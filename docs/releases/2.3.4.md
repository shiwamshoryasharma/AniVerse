# AniVerse 2.3.4 for Windows x64

- Stop when the selected HLS playlist or a declared video variant is protected or invalid. Older captured clear playlists no longer replace a failed selected root.
- Keep a direct playing playlist bound to its own video renditions. Unrelated observations from earlier playback cannot select a different captured root.

This corrects download selection from 2.3.3. The supported download flow remains clear, complete on-demand HLS with accessible audio and WebVTT captions. Encrypted/DRM-protected streams, live playlists, byte ranges and discontinuities remain unsupported; source compatibility is not guaranteed.

Install with **Settings → About → Check for updates**. This release uses the existing AniVerse Electron profile and signed updater.
