# AniVerse 1.5.2

## Added

- Three complete interface themes in Settings: **Classic** (the original style), **Aurora** and **Paper**. Theme exports retain style selection and accept older presets.
- **Anime4K upscaling** in Settings and player controls: Mode A/B/C, A+A/B+B/C+A, optional darken/thin lines and aspect-preserving output up to 4K. Compatible source players use the existing video element; blocked pixel access leaves original playback running.
- **Google Drive app-data import/export** using each user's own Desktop OAuth client JSON. Includes PKCE sign-in, encrypted main-process credentials, import preview, bounded/validated backups and merge behavior.
- A stable Drive protocol: **AniVerse Sync/aniverse-backup.v1.json**. Shared-folder links/IDs avoid name ambiguity; broader shared-folder access requires explicit Google consent.
- **Sender-side 4K casting** for opened local videos. Embedded FFmpeg/FFprobe 9.0.2 runs Anime4K with Vulkan and encodes a 3840 × 2160 HEVC/AAC HLS stream. Computation runs on the sender, with available NVIDIA/Intel/AMD encoding and a CPU fallback.
- Distinct icons for Profile & appearance and Interface themes.

## Behavior and limits

- Drive sync uploads app data only. Credentials, source lists, sessions, local video paths/files and watch insights are excluded. Export replaces the fixed backup; import preserves unrelated/newer local records and never automatically pushes to AniList/MAL.
- Browser filtering respects CORS/protected-media restrictions and does not extract website media streams. Native PiP and receiver players use their own rendering.
- Sender-side 4K requires a Vulkan-capable sender, sufficient encoding/LAN capacity and a 4K HEVC-capable Google Cast receiver. It applies to opened local files; direct casting remains available for other supported native media. Original website streams are not extracted.
- Embedded tools ship/update inside AniVerse. No system FFmpeg installation is required.
- GPU upscaling does not recover detail that is absent from the source, and frame counters do not certify lip sync.

## Validation

Typecheck, lint, unit tests, hidden Electron UI checks, and real embedded 4K encode/HEVC/AAC/HLS token/range checks are run for this release. Detailed current results are recorded under test/artifacts/release-1.5.2-*.

Google OAuth/Drive UI checks use controlled responses with a real loopback callback. A real Google account and physical 4K TV were not used. No live website compatibility, Windows install/uninstall/update-install, or image-based model-quality certification is claimed.
