# AniVerse2 3.0.8 for Windows x64

- Floats the Classic, Studio, and Atlas vertical navigation menus, with room for the app content and scrolling in short windows.
- Adds Dark, Light, GitHub Dimmed, and VS Code Dark+ colour palettes to **Settings → Interface themes**.
- Applies the palettes throughout the AniVerse2 interface, including menus and dialogs. The Light palette keeps text readable on artwork and player controls.
- Keeps existing theme, layout and individual colour preferences available.

Existing AniVerse2 installations can update from **Settings → About → Updates**.
