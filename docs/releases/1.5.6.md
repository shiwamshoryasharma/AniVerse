# AniVerse 1.5.6

## Fixed

- **TVs visible in Windows Cast:** both episode and native-player casting menus now include Windows wireless display (Miracast). **Find wireless displays** opens the Windows chooser, with Display settings and TV audio actions alongside it. Miracast and Google Cast controls are clearly separated.
- **Website Anime4K failure:** **Use compatibility upscaling** processes a video-only capture of the selected source view on the local GPU when direct video pixel access fails. It works with cross-origin player frames while retaining source audio and controls. All six presets remain available.
- **Google Cast discovery:** combines SRV/TXT/address records across response packets, resolves missing records, scans active IPv4 interfaces and handles network errors. Unrelated address records are no longer assigned to a device.
- Capture grants are shared through one broker, restricted to owned source views, single-use and short-lived before activation. Stop/navigation releases the overlay, stream and encoder resources.

- A home-metadata cache key now uses a consistent time bucket, fixing an existing second-boundary cache miss exposed by final regression testing.

- **Darken / Thin effects:** repaired vendor shader code that does not compile under WebGL 1. This affected native and website filtering when line effects were enabled.
- **Scaling playback timing:** only one GPU frame is allowed in flight. Late/seek-stale filtered pictures are discarded; slow rendering tries smaller shader models and then the original picture, preserving the original audio/media clock.

## Using the fixes

For a TV listed by Windows + K, use **Cast to TV → Windows wireless display → Find wireless displays**. Windows projection can share the desktop and other visible apps. Windows owns the connection and selected display/audio mode; disconnect through Windows + K. Available 4K modes depend on the PC, TV and connection.

For a website reporting an Anime4K failure, keep the episode playing, enable Anime4K and choose **Use compatibility upscaling**. Prefer player-only mode. The status shows **Compatibility · Anime4K …** once active. Protected content or an unavailable GPU can still block processing.

## Validation

Typecheck, lint, 177 unit tests, real Electron casting/upscaling UI checks, cross-origin iframe capture/GPU presets, original audio/playback and stop/navigation cleanup are covered. Google Cast encoder checks use a controlled receiver transport. Embedded FFmpeg/FFprobe stays inside the app.

Physical-TV pairing, every live source website, DRM playback and actual installer/update installation are not certified. Google Drive’s fixed app-data backup format is unchanged.
