# AniVerse 0.3.0

- Fix player-only mode allowing website overlays/navigation to cover the video.
- Exclude hidden and CAPTCHA/challenge frames when selecting the episode player.
- Keep the existing player, audio, controls and subtitles together; no stream URL extraction.
- Add Playback Rescue: video resolution, buffered seconds, presented frame rate, dropped-frame rate, stall detection and recovery at the current position.
- Preserve position and paused/playing state when changing a source's SUB/DUB option or server where the replacement episode supports seeking.
- Request the dedicated/high-performance GPU at startup on hybrid systems. Settings → Graphics & GPU now shows detected adapters, the active GPU and hardware video-decode availability, with Windows Graphics settings guidance.
- Add separate colored Graphics & GPU menus, illustrated laptop/NVIDIA setup guides, and remove the executable path from the GPU UI.
- Add saved UI font choices and a live preview in Profile & appearance.
- Make signing/update checks explicitly load the Windows Security module when inherited PowerShell module paths differ.
- Keep embedded video rendering active when the guest page is occluded.

Validation: 111 unit tests and 25 rendered-player assertions, plus typecheck/lint/build, live SUB/DUB playback, GPU-menu checks, font persistence across restarts and packaged-app smoke checks. Live source results and packaging validation are recorded locally under test/artifacts.

GPU selection remains subject to OS/driver policy. NVIDIA RTX Video enhancement is driver-controlled; this release does not bundle the RTX Video SDK or claim that AI upscaling is active. Browser counters diagnose video delivery, not audio lip-sync.
