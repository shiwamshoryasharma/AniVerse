# AniVerse 2.3.0 for Windows x64

This Windows release brings AniVerse2’s user-facing features to the Electron edition. It upgrades the existing AniVerse installation in place and uses the same profile, saved source TXT, library, watch history and account settings.

- Explore five layouts, dark and light themes, GitHub Dimmed and VS Code colours, a ten-colour palette, independent colour controls and adjustable display scale. The floating vertical menu starts compact and expands on demand.
- Click Search for suggestions based on your local viewing history. Completed titles remain in regular search with a completion label and are excluded from recommendations.
- Use **Quantum Audio** and **Download MP4** below the player. The MP4 action opens Save As and supports compatible public direct MP4 and finite, unencrypted HLS. Choose a default folder in **Settings → Player**.
- Review blocked requests, redirects and popups with the chart, time range and source filters in **Settings → Privacy & blocking**.
- Choose a Windows GPU preference in **Settings → Graphics & GPU**. Home limits its artwork and background animation work.
- Source episodes retain their familiar SUB/DUB controls, now-playing card layout and thumbnails when the website supplies artwork.

**Settings → About → Check for updates** installs the signed Windows release from AniVerse 2.2.5. The optional **Update AniVerse to AniVerse2** action continues to offer the separately installed Tauri edition.
