# AniVerse2 3.0.9 for Windows x64

- Vertical navigation starts in icon-only mode and expands into a narrower labelled panel.
- Website playback keeps its original video size while the Watch page scrolls. The player-only view is preserved, with Show site still available.
- Download MP4 and AniVerse Quantum Audio are visible beside the playback controls. Episode cards show available source thumbnails and keep their status readable.
- The blocking report shows a stacked count chart by source, a legend, filters, and exact totals.
- Home starts less speculative work. Filter rules load when first needed, and Anime4K sizes its render surfaces to the display area.
- Graphics & GPU offers System, Dedicated GPU preferred, and Power-saving GPU preferred. Compatibility video remains available with supported GPUs.
- Uses the installed WebView2 Evergreen Runtime when available. The installer includes Microsoft's bootstrapper for computers that need WebView2. Website content runs inside WebView2's renderer sandbox with access to native commands restricted to the AniVerse2 interface.
