# AniVerse 2.2.3 for Windows

- **Source redirects:** Sources and Watch can open an enabled configured destination in its own browser session. Watch reopens the requested episode there.
- **SUB and DUB:** AniVerse can use the site's audio controls while the player is isolated. Sources that group servers by audio show the available SUB and DUB options alongside their corresponding servers. The selection follows the site's active server.

Installed Windows copies can check for the update in **Settings → About → Updates**.
