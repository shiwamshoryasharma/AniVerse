# AniVerse2 3.0.4 Preview for Windows x64

This playback update restores AniList title details in AniVerse2 and opens configured websites in the embedded WebView2 player. It adds source navigation and SUB/DUB selection where the website exposes those options. AniVerse2 keeps the saved source TXT and profile when updating from the earlier preview.

Use Settings → About → Updates in AniVerse2, or run the Windows x64 setup from this release. The installer uses the existing preview identity and retains AniVerse 1 for rollback. Full browser-session migration, account sync, casting parity and automatic AniVerse 1 removal are still in development.
