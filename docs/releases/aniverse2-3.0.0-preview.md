# AniVerse2 3.0.0 Preview for Windows x64

This signed preview tests the Tauri 2 installer and the profile transfer from AniVerse 2.2.4. From AniVerse, open **Settings → About → Updates → Update AniVerse to AniVerse2** to try the migration. The direct installer is also available for a fresh preview installation.

The installer runs side by side with Electron. It copies your active source TXT, preferences, library, history and compatible app cache into a separate preview profile. After the test, you can reopen AniVerse 2.2.4 with your original profile.

The preview includes the Tauri-hosted React interface, new desktop branding, and new palettes. Website playback and SUB/DUB switching, account sessions, Tauri auto-updates, and automatic removal of Electron are pending. Continue using AniVerse 2.2.4 for those features.
