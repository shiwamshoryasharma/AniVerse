# AniVerse 1.0.0

AniVerse 1.0 adds a local workspace around the browser and native player. Official signed releases contain no streaming-site list. Users choose their websites and media.

## Added

- **Scene bookmarks:** save the current playhead with private notes and tags; search, edit, delete and revisit scenes.
- **Episode Toolkit:** one timeline for bookmarks and intro/outro ranges beneath the Watch player, with the B bookmark shortcut.
- **Skip maps:** save intro/outro boundaries per title and explicitly enable auto skip. Automatic reuse requires the same source and a similar runtime.
- **Spoiler Shield:** reveal app synopses/comments on demand and hide future unwatched episode names/thumbnails.
- **Subtitle Studio:** import UTF-8 SRT/WebVTT, choose primary and secondary native captions, adjust their offsets and save caption style.
- **Weekly planner:** fit available unwatched episodes from up to 20 library titles into a seven-day budget.
- **Local collection:** index selected video folders, confirm title/episode matches and play without moving the original files.
- **Theme presets:** save/apply visual settings and import/export strictly validated JSON. UI font preferences are included.
- **Local watch insights:** optional playing-time and dropped-frame estimates, disabled by default, with a separate deletion control.
- Separate colored Workspace menus and a dedicated Theme presets Settings menu.

## Reliability and documentation

Additive SQLite migrations retain existing library, sync, progress and account data. Folder scans lock before opening the picker, skip symbolic links and preserve records when scans are incomplete. Local-file playback validates the selected roots in the main process and returns a capability URL rather than a filesystem path.

Scene saving reads the current playhead on demand. Skip actions stop when the originating component is disposed. Website Toolkit controls reuse Watch's probe samples instead of adding a second periodic website probe.

The README, disclaimer, privacy notice and in-app About notice now explain browser navigation, local storage/cache, casting, user-supplied sources, rights, copyright contacts and maintenance limits. Absolute “stores nothing” and blanket rejection-of-notice claims have been removed.

## Limits

- Website playback retains the site's own player; source audio, captions and server availability remain site dependent.
- Dual-caption overlays are for the native player inside AniVerse; they do not replace website captions or travel to picture in picture/cast receivers.
- Website sampling is periodic. Skip timing can lag by three seconds, and some players prevent observation/control.
- Bookmark/range timing can differ across editions. Frame-drop ratios do not certify audio/video synchronization.
- GPU preference requests and active-adapter reporting remain available from 0.3. Windows/Chromium/driver policy still chooses the actual render/decode path. No custom GPU driver or guaranteed NVIDIA AI enhancement is included.
- Collection scans cover up to 2,000 videos and six nested levels. Chromium codec support determines playback.
- Plans and insights are estimates. Rebuild plans after progress/list changes.
- Windows x64 is the packaged platform validated for this release. Installer/uninstaller and real installed-updater end-to-end tests were not performed.
- Watch Together was removed from this release at the user's request.

## Validation

Passed on Windows x64: typecheck, lint, production/signed build, 131 unit tests, 10 packaged Electron Workspace checks, 25 original-player focus/media assertions, both GPU preference/UI modes, and packaged HLS/DASH/MP4 playback with no renderer errors. The installer signer matches the pinned project certificate; its update-feed digest and public-only resource configuration were verified. The certificate is self-signed and Windows reports its untrusted root as expected.

Local reports and screenshots are kept under test/artifacts; they are not shipped as product data.
