# AniVerse 2.2.2 for Windows

- Watch recovers from redirects to an enabled configured HTTPS source. It opens the requested episode through that source's own session and retains the bounded fallback order.
- The optional **Midnight** theme in **Settings → Interface layouts** brings navy surfaces, mint controls and clearer episode selection. Your original layout and colour preferences remain available.
- **Save MP4 as…** is available on the right-click menu of a supported direct HTTPS video or link from the source's configured origin. Set the starting folder in **Settings → Player → Downloads**, then choose a new filename in the Windows save dialog. It saves public MP4 files without using website login state, with an 8 GiB limit. Streaming playlists, embedded players that use blob URLs and access-controlled media require the provider's own offline tools.
- Watch skips playback probes during automatic navigation and avoids overlapping probes.

The Windows host uses the existing embedded Rust module to check redirect destinations, direct MP4 URLs and MP4 headers. Electron manages browser sessions and the Windows save dialog.

This installer updates the Windows edition. Android has an independent release version.
