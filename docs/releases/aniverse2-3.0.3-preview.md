AniVerse2 now has its own signed Windows self-updater. Open **Settings → About → Updates** to check, download, or restart to install. Automatic checks and downloads are configurable. About shows the installed version, Tauri and WebView2.

Install this version once using the signed EXE if you already have an AniVerse2 3.0.0–3.0.2 preview. The new installer keeps the existing preview profile. Later releases use AniVerse2’s own GitHub feed.

From AniVerse 2.2.4, **Settings → About → Updates → Update AniVerse to AniVerse2** still migrates your saved sources, history and settings. The preview installs alongside Electron.
