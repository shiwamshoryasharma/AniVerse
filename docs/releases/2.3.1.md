# AniVerse 2.3.1 for Windows x64

- Click Search to get recommendations from recent watch history and continue-watching progress. Previously watched titles are excluded from recommendations. Completed titles remain searchable and show their completion badge.
- Quantum Audio stays enabled during ordinary scrolling, player controls, and on-screen interaction. The Rust headphone effect improves stereo depth and distinguishes front, side and rear channels on compatible surround tracks.
- **Download MP4** now works without installing a separate Visual C++ runtime. It preserves direct MP4 files, joins compatible finite clear HLS and converts public direct TS, WebM, MKV, MOV, and other supported video containers to MP4. You can choose the folder in **Settings → Player**.

Install with **Settings → About → Check for updates**. This release uses the existing AniVerse Electron profile and signed updater. AniVerse2 has a separate update channel.
