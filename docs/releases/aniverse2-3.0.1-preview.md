This signed Windows x64 preview opens the active streaming-sites.txt in your editor and refreshes the source list when AniVerse2 regains focus. It restores the in-app Windows title bar with minimize, maximize, restore and close controls.

From AniVerse 2.2.4 use **Settings → About → Updates → Update AniVerse to AniVerse2** to copy your saved source list, settings and history. If you installed an earlier AniVerse2 preview, run this setup over it to keep its preview profile.

AniVerse2 installs alongside Electron. Website playback and SUB/DUB switching, account sessions, Tauri auto-updates and automatic Electron removal remain pending.
