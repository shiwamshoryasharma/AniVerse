This signed Windows x64 preview restores AniList Home and Latest Episodes in the Rust backend. It uses your existing source file and preserves the profile when installed over an earlier AniVerse2 preview.

From AniVerse 2.2.4, use **Settings → About → Updates → Update AniVerse to AniVerse2** to copy your saved source list, settings and history. AniVerse2 installs alongside Electron.

Website playback and SUB/DUB switching, account sessions, Tauri auto-updates and automatic Electron removal remain pending.
