# AniVerse2 3.0.6 for Windows x64

- Adds AniVerse Quantum Audio to compatible website players. Open the waveform control in Watch to enable the effect. Supported players keep the effect active when switching between SUB and DUB, and sites that block audio processing keep their original audio.
- Fixes player-only mode so a late-loading website player fills the viewing area and the source header, episode list and chat stay out of view. Show Site restores the full page.

Existing AniVerse2 installations can use Settings → About → Updates. This signed Windows x64 installer keeps the existing installation and updater identity.
