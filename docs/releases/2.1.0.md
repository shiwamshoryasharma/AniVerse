# AniVerse 2.1.0

Working source-backed DUB and SUB catalogues, including a fresh installation.

- 🔊 **DUB means SUB + DUB.** A series stays in DUB when dubbed episodes trail subtitled episodes—for example, SUB 12 / DUB 11. The newest episode does not need its own dub.
- 🎬 **SUB includes both.** Mixed SUB/DUB series and SUB-only series appear together. Episode-list filtering still checks each episode's own availability.
- 🌐 **Read the source catalogue.** Home Latest Episodes and Browse now read public cards and use the selected website's own audio controls and pagination. Choose a configured source and see its real episode counts without watching titles first.
- 🔎 **Keep discovery useful.** Public metadata IDs match source titles to AniList cards and existing metadata filters. Unmatched cards open their original source page. ALL retains AniList discovery.
- ⚡ **Reliable switching.** Rapid category changes cannot cancel an in-flight result that the final category still needs.
- 🔒 **Keep source isolation.** Catalogue reads use one bounded, muted, sandboxed browser in the correct source session. Temporary sessions are discarded; cookies stay isolated and no watch records or sync entries are created.

This corrects 2.0.2's session-observation filter, which could show an empty DUB list before viewing titles. Unreadable or unsupported source layouts now offer Retry and Open source; an error is not treated as proof that a source has no dubbed series. Availability and pagination come from the selected source, and may differ between websites.

Validation: TypeScript/lint, 250 unit tests, 14 integrated catalogue/series UI checks, the signed package and 14 production security/playback checks. A fresh native app profile also showed the real configured source's mixed SUB 12 / DUB 11 series in DUB and both mixed/sub-only series in SUB, with no prior watched-title hints. Physical TV/audio and installer/update installation were not tested.
