# AniVerse 2.2.5 for Windows

Open **Settings → About → Updates → Update AniVerse to AniVerse2** to install AniVerse2 alongside AniVerse. The migration checks the signed setup and carries over the saved source list, settings, library, history and compatible AniVerse cache. AniVerse stays installed with its original profile. You can remove it later from Windows Settings.

If GitHub limits the release list, the button checks the separately signed AniVerse2 Windows manifest. AniVerse updates retain their existing Windows feed. Supported saved website cookies can transfer to AniVerse2 3.0.5 or newer under the same Windows user. Some sites may require you to sign in again.
