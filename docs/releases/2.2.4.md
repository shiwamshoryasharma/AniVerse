# AniVerse 2.2.4 for Windows

This is the final Electron release of AniVerse for Windows. Open **Settings → About → Updates → Update AniVerse to AniVerse2** to check the separate AniVerse2 Windows release channel.

The update option downloads an installer only after finding a signed, compatible AniVerse2 release and asking for confirmation. The handoff includes the active source configuration folder and the current profile, so the AniVerse2 migration can carry over the saved TXT, settings, and watch history.

AniVerse2 is a separate release. Until a signed AniVerse2 installer is available, the update option reports that and AniVerse stays open.
