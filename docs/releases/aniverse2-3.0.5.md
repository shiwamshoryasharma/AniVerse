# AniVerse2 3.0.5 Preview for Windows x64

- Restores Windows playback buffer metrics and fixes a Watch screen crash.
- Improves series lookup using title aliases, shorter searches, and the website's full results.
- Adds interface scaling under Settings → Graphics & GPU and fits the startup window to the display.
- Adds AniVerse Quantum Audio for headphone playback in the built-in local player. A Rust audio processor adds binaural depth and light bass while the existing player controls timing. Websites keep their original audio.
- Adds video-only mirroring for eligible website players through Chrome. Audio continues in AniVerse2. Physical receiver coverage varies.
- Accepts eligible encrypted website-session cookies from the AniVerse 2.2.5 bridge. AniVerse 1 stays installed alongside AniVerse2.

Existing AniVerse2 users can update from Settings → About → Updates. The signed Windows x64 setup uses the existing preview identity.
