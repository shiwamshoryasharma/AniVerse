# AniVerse 2.2.1 — Windows

Watch History now has comfortable **Grid | List** layouts, date groups, title/source search, visible episode progress and exact-source episode Resume actions. The layout is remembered on this device. Individual removal and a confirmation before Clear history preserve your library, favourites and episode progress.

Website searches now ignore hidden/offscreen search widgets; offscreen episode controls and transparent original media remain discoverable.

This patch preserves the 2.2.0 source-learning, checkbox filters, animations, player, security controls and desktop enhancement/casting features. Existing profiles remain compatible; Android uses its own app-private data and independent 0.1.0 version.

The installer uses the existing self-signed Windows project certificate. Verify the release SHA-256 and certificate as described in [Installer](../INSTALLER.md). Previous releases are retained.
