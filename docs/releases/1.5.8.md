# AniVerse 1.5.8

Sharper playback, broader search and a private viewing option, with a seasonal dark palette.

## Changes

- 🎬 **Episode cards:** a thumbnail-led index with episode numbers, current/watched states, list/grid switching and search. Spoiler Shield still hides unwatched artwork and titles. Missing images use a quiet placeholder.
- 🪔 **Diwali × Halloween:** midnight-violet surfaces, warm ivory text, amber/gold highlights and subtle episode-card detail. Applied automatically with this update through December 31, 2026. Your previous palette returns on January 1, 2027, including if AniVerse stays open. Switch away earlier in Settings; the palette remains available for manual use afterward.
- 🔎 **Broader title discovery:** English, romaji and Japanese names, alias-aware ranking, partial-word results and bounded typo fallback. Search is catalogue-wide; playback tries configured sources rather than assuming the first source has the title.
- 🔁 **Automatic source recovery:** missing titles, episodes and rendered missing-page responses advance through enabled sources once. A clear exhausted state offers Retry sources. Security challenges remain visible for you to complete.
- 🛡️ **Private playback:** start a temporary incognito session from the header or choose Keep private on a title. New progress, history, watch insights, learned links and account-sync jobs are suppressed. Private-title records are excluded from new app-data backups and imports respect local private rules.
- 🍪 **Temporary website storage:** private playback uses memory-only source sessions, independent from normal logins. Leaving a private title or ending incognito closes its owned guests and clears its storage. Permanent title rules survive restart; temporary incognito does not.
- 🖼️ **Normal and Anime4K player layout:** repair offset/fixed-size videos and ratio wrappers, including embedded player documents. Align direct Anime4K overlays with transformed containers while preserving the source video, audio, controls and aspect ratio.
- 🚫 **Updated popup blocking:** block all new windows while popup protection is enabled, including same-site popups that previously replaced the player. Guard off-site top-frame redirects while retaining embedded player navigation. Cosmetic filters now target the requesting iframe.
- 🔄 **Filter updates:** checks hourly, refreshes lists after 24 hours, retains working cached rules offline, and offers Settings → Privacy → Update filters.
- 🖥️ **Stable Windows interface:** remove remaining whole-interface backdrop blur and default to stable software window composition. GPU video decoding, WebGL and embedded encoding remain available where supported. Settings → Graphics & GPU offers a device-local Stable/Accelerated choice; restart to apply it.
- 📖 **In-app changelog:** colour-coded highlights and feature links describe this update inside AniVerse.

## Scope and limits

Users supply sources through their local TXT configuration. No source list is bundled. Website playback navigates rendered pages and uses their own players; it does not extract media streams.

Private mode controls AniVerse's new records and temporary source storage. It does not make browsing anonymous, remove prior local/remote records, undo requests already sent, or hide activity from websites, metadata providers, networks or a selected casting device. Manually saved library entries remain on this device; future provider sync and new backups exclude private titles.

The cropped-player fixture reproduced incorrect inner video dimensions and offsets. The whole-window probe reproduced CSS backdrop blur; the intermittent desktop GPU-driver symptom itself was not reproduced. Stable composition is a tested compatibility option, with additional CPU/readback cost possible.

Validation uses isolated neutral sources, controlled provider responses and real Electron/GPU/video paths. No live source catalogue, real sync account, physical TV playback, installer/update installation, protected media or every GPU/monitor combination is certified.
