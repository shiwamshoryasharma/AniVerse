# AniVerse 2.3.2 for Windows x64

- Restore the selected desktop theme on startup. Previously, Home could show the default Ion colours until you opened **Settings → Interface themes**, even though your chosen theme was still saved.
- Load custom header, page, button and other interface colours with the app, so reopening AniVerse restores the colours you selected.

Install with **Settings → About → Check for updates**. This release uses the existing AniVerse Electron profile and signed updater. AniVerse2 has a separate update channel.
